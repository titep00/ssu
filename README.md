# 데이터 분석 교실

중학교 정보 수업을 위한 **데이터 전처리 · 시각화 · 분석** 웹 도구입니다.
학생들은 공공데이터를 직접 내려받아 처리하는 복잡한 과정 없이, 브라우저에서 바로
데이터를 정리하고 그래프를 그린 뒤 분석 결과를 제출할 수 있습니다.

- **학생**은 반 코드와 이름만으로 접속합니다(회원가입 없음).
- 학생이 제출한 과제는 **다른 학생에게 절대 보이지 않습니다.**
- **선생님(관리자)** 만 전체 제출물을 확인하고 점수·피드백으로 채점할 수 있습니다.

---

## 주요 기능

- 선생님이 올린 CSV 데이터를 고르거나, 학생이 직접 CSV 파일 업로드
- 결측치(빈 값) 제거 · 필터 · 정렬 등 간단한 전처리
- 막대/꺾은선/원 그래프 생성
- 그래프 이미지 + 분석 글 제출
- 선생님 전용 채점 화면 및 제출물 CSV 내보내기(백업)

## 처음 배포하기 (선생님용, 약 15분)

개발 지식이 없어도 따라 할 수 있도록 정리했습니다. **무료**로 인터넷에 올릴 수 있습니다.

### 1단계. 준비물

- GitHub 계정 (코드 저장용, 무료)
- Vercel 계정 (사이트 배포용, 무료) — GitHub 계정으로 바로 가입 가능
- Neon 계정 (데이터 저장용, 무료) — Vercel에서 클릭 몇 번으로 연결됩니다

### 2단계. 코드 올리기

이 프로젝트를 본인의 GitHub 저장소로 올립니다(포크 또는 새 저장소에 업로드).

### 3단계. Vercel에 배포

1. [vercel.com](https://vercel.com) 에 GitHub 계정으로 로그인
2. **Add New → Project** 클릭 후 이 저장소를 선택
3. 아직 **Deploy를 누르지 말고**, 먼저 데이터베이스를 연결합니다(4단계).

### 4단계. 데이터베이스(Neon) 연결

1. Vercel 프로젝트의 **Storage** 탭 → **Create Database** → **Neon** 선택
2. 안내에 따라 생성하면 `DATABASE_URL` 이 프로젝트에 **자동으로 추가**됩니다.

### 5단계. 환경 변수 3개 확인/추가

Vercel 프로젝트 **Settings → Environment Variables** 에서 아래를 설정합니다.

| 변수 이름 | 값 | 설명 |
|---|---|---|
| `DATABASE_URL` | (Neon이 자동 추가) | 데이터 저장소 주소 |
| `SESSION_SECRET` | 32자 이상 무작위 문자열 | 로그인 보안용 (아무 긴 문자열) |
| `ADMIN_PASSWORD` | 원하는 비밀번호 | 선생님 로그인 비밀번호 |
| `CLASS_CODES` | (선택) `1-1,1-2,1-3` | 허용할 반 코드. 비우면 모든 코드 허용 |

> `SESSION_SECRET` 예시 생성: 아무 사이트의 무작위 문자열 생성기를 쓰거나,
> 영문+숫자를 40자 정도 아무렇게나 입력해도 됩니다.

### 6단계. 배포 후 데이터베이스 표 만들기 (최초 1회)

배포가 끝나면 데이터를 담을 표(테이블)를 한 번 만들어야 합니다.

**로컬 컴퓨터에서 실행 (권장)**

```bash
# 1) 이 프로젝트를 내려받은 폴더에서
npm install

# 2) .env.example 을 복사해 .env.local 을 만들고 DATABASE_URL 을 채웁니다
#    (Neon 콘솔에서 복사하거나, `vercel env pull .env.local` 로 가져올 수 있습니다)

# 3) 표 생성 (한 번만)
npm run db:init
```

성공하면 `데이터베이스 테이블 준비 완료` 메시지가 나옵니다.

이제 배포된 주소를 학생들에게 알려주면 됩니다. 끝!

## 수업 준비 (선생님)

1. 배포된 주소로 접속 → **선생님으로 시작하기** → 관리자 비밀번호로 로그인
2. **데이터셋 관리** 에서 수업에 쓸 CSV를 업로드합니다.
   - `sample-data/` 폴더에 바로 쓸 수 있는 예시 CSV 3종이 들어 있습니다.
3. 학생들에게 **주소 + 반 코드**를 안내합니다.
4. 수업 후 **제출물 채점** 에서 확인·채점하고, 필요하면 **CSV 내보내기** 로 백업합니다.

---

## 로컬에서 실행하기 (개발/테스트)

```bash
npm install
# .env.local 에 DATABASE_URL, SESSION_SECRET, ADMIN_PASSWORD 설정
npm run db:init   # 최초 1회
npm run dev       # http://localhost:3000
```

## 개인정보 안내

- 학생 식별은 **반 코드 + 번호 + 이름**만 수집하며 그 외 정보는 저장하지 않습니다.
- 수업 종료 후에는 관리자 화면에서 제출물을 삭제하거나, CSV로 내려받아 보관한 뒤
  데이터베이스를 정리하는 것을 권장합니다.
- 무료 데이터베이스는 백업이 아닙니다. 중요한 결과는 **CSV 내보내기**로 따로 저장하세요.
